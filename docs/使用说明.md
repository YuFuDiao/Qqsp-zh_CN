# Qqsp 播放器汉化版 — 使用说明

适用于 Qqsp **1.9.0**（Windows 64 位）。

## 一、安装

把这两个文件放到 Qqsp 的安装目录，覆盖同名文件：

```
Qqsp-1.9.0-win64/
  Qqsp.exe            <- 用本仓库 out/Qqsp.exe 覆盖（覆盖前请备份原文件！）
  Qqsp.zh_CN.qm       <- 新增
  Qqsp.zh-CN.qm       <- 新增（连字符别名，两份内容完全一样）
```

双击 `Qqsp.exe`，界面即为中文。

## 二、这是免费的

本汉化免费分享。如果你为它付过钱，说明你被骗了 —— 原作者只发布免费版本。

## 三、切换语言

`设置 → 选项 → 语言`，可选：

* **简体中文**
* English
* Русский

> 列表里可能出现两条「简体中文」，这是连字符别名的副作用（见下节），两条都能用。

## 四、界面突然变回英文怎么办

这是 Qqsp 1.9.0 的一个已知坑：程序按配置里的语言 ID 去找 `Qqsp.<ID>.qm`。中文 Windows 上系统区域名是 `zh-CN`（**连字符**），而语言包文件名是 `zh_CN`（**下划线**）——差一个字符就找不到，界面全英文。

本汉化已通过额外放一份 `Qqsp.zh-CN.qm` 做了永久兜底，两种写法都能命中。若你仍然遇到英文界面：

1. 打开 `设置 → 选项 → 语言`，选一次「简体中文」，确定；
2. **不要手工编辑** `%APPDATA%\Qqsp\Qqsp.ini` 里的 `language` 行（写错就会掉回英文）；
3. 想彻底不受系统设置影响：在 `Qqsp.exe` 同级目录新建 `custom.ini`，内容为

```ini
[application]
language=zh_CN
```

程序检测到它就会改用便携模式，所有设置只读写这个文件。

## 五、还原成原版

1. 用你备份的原版 `Qqsp.exe` 覆盖回去；
2. 删掉 `Qqsp.zh_CN.qm` 与 `Qqsp.zh-CN.qm`；
3. 若需要，把 `%APPDATA%\Qqsp\Qqsp.ini` 里的 `language` 改回 `en_US`。

## 六、会汉化什么，不会汉化什么

**已汉化**：主窗口全部菜单与工具栏、各面板标题、选项对话框全部条目、关于对话框、Qt 的文件选择 / 字体 / 颜色 / 消息框等标准对话框按钮，以及程序内部的引擎错误提示（如「除以零」「未找到位置」）和窗口标题。

**未汉化**：

* **游戏剧情文本** —— 那在 `.qsp` 游戏文件内部，属于另一个汉化工程，与本播放器无关；
* 极少数只在程序致命崩溃时出现的内部诊断字符串（如 `bad allocation`）。
